Los iconos de las aplicaciones Craft se copiaron sin modificar de
`storytold/craft-launcher/assets/app-icons/`. Sus fuentes originales y licencias
están detalladas en `ATTRIBUTION.md`; se incluyen MIT, Apache y las licencias de
SolidCraft. Se usan para identificar las fuentes que compila esta herramienta.

No se incluyen el logotipo ni la marca «A» de ArtCraft, ni el icono de Craft
Anything. La tarjeta de este último utiliza un icono genérico del escritorio.
La atribución original de upstream se conserva íntegra como referencia.
